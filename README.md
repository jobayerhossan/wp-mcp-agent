# WordPress MCP Agent

> **Development in progress — do not install on production sites.**

Standalone, self-hosted WordPress plugin for MCP-based management: posts, pages, media, Elementor, theme and plugin source files, diagnostics, backups, and rollback.

This repository is being extracted from the maintained WordPress agent as a **separate project**. It does not change the original plugin.

Security: never commit site secrets or use the development build on a production WordPress site before reviewing the permissions and configuration.
